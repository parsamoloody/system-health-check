A Linux system health checker. It collect system resource metrics and evaluates system health based on resource availability and usage.

#### Requirements
- gcc compiler


#### Build
```bash
make
```
#### Run

```bash
make run
```

#### Cleanup and rebuild
```bash
make clean && make
```
### Supported Platforms

- Linux🐧 (Ubuntu, Debian, Arch, Fedora, AlmaLinux, etc.)
